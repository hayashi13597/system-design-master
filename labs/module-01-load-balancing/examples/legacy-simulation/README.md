# Ví dụ mô phỏng cũ

Chỉ lưu để tham khảo thuật toán và đối chiếu bản v1. Không phải runtime chính, không chứng minh durability hay multi-node consistency. Các benchmark cũ có thông báo thành công cố định; không dùng để xác nhận tính đúng đắn. Xem README của lab và runtime/ cho đường chạy đã được kiểm thử.
